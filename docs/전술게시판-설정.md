# 전술 게시판 켜기 (Supabase)

> 게시판은 **꺼진 채로 배포됩니다.** 아래를 마치면 켜집니다.
> 설정 전에도 게임은 그대로 돌아가고, 화면에서 게시판만 안 보입니다.

무엇을 하는 것인가 — 닉네임과 대전 코드를 남겨 두면, 다른 사람이 목록에서 골라
**그 자리에서 바로 붙어 볼 수 있게** 하는 것입니다. 상대가 접속해 있을 필요가 없습니다.

걸리는 시간은 10분쯤입니다. 카드 등록 같은 건 없습니다(무료 티어).

---

## 1. 프로젝트 만들기

1. <https://supabase.com> 에서 가입하고 **New project** 를 누릅니다.
2. 이름은 아무거나(`kmd26` 등), 지역은 **Northeast Asia (Seoul)** 로 두면 빠릅니다.
3. 데이터베이스 비밀번호를 정합니다 — **이건 어디에도 붙여 넣지 않습니다.** 그냥 보관만 하세요.

## 2. 표와 권한 만들기

왼쪽 메뉴 **SQL Editor** → **New query** 에 아래를 **그대로** 붙여 넣고 **Run**.

```sql
create table if not exists public.plans (
  id         bigint generated always as identity primary key,
  created_at timestamptz not null default now(),
  nick       text    not null check (char_length(nick) between 1 and 12),
  note       text             check (note is null or char_length(note) <= 40),
  team       text    not null check (char_length(team) <= 16),
  code       text    not null check (code ~ '^KM26D1-[A-Za-z0-9_-]{40,80}$'),
  data_hash  text    not null check (char_length(data_hash) <= 24),
  hidden     boolean not null default false,
  unique (code)
);

alter table public.plans enable row level security;

-- 숨기지 않은 것만 누구나 읽는다
create policy "read_visible" on public.plans
  for select using (hidden = false);

-- 누구나 등록은 할 수 있다
create policy "insert_any" on public.plans
  for insert with check (true);

-- ⚠ update·delete 정책은 **만들지 않습니다.**
--   정책이 없으면 anon 키로는 아무도 고치거나 지울 수 없습니다.
```

이 SQL 이 하는 일:

| 장치 | 막아 주는 것 |
|---|---|
| `check (code ~ '^KM26D1-…')` | 대전 코드 모양이 아닌 아무 글이나 올리는 것 |
| `unique (code)` | 같은 라인업을 여러 번 올려 목록을 도배하는 것 |
| `char_length` 제한 | 닉네임·소개에 긴 글을 밀어 넣는 것 |
| update·delete 정책 없음 | 남의 글을 고치거나 지우는 것 |
| `hidden` + 읽기 정책 | 문제되는 글을 **지우지 않고 감추는** 것 |

## 3. 열쇠 두 개를 코드에 넣기

**Project Settings → API** 에서 두 값을 복사해 `src/board/board.js` 맨 위에 붙여 넣습니다.

```js
export const BOARD = {
  URL: "https://여기가프로젝트주소.supabase.co",
  KEY: "eyJhbGciOi...",   // anon public
};
```

> ⛔ **`service_role` 키는 절대 넣지 마세요.** 그건 모든 권한을 가진 열쇠라, 넣는 순간
> 누구나 표를 통째로 지울 수 있게 됩니다. 넣어야 하는 것은 **`anon` `public`** 이라고
> 적힌 쪽입니다. anon 키는 브라우저에 내려가는 것이 정상이고, 그 키로 할 수 있는 일은
> 위에서 만든 정책이 허락한 것뿐입니다.

넣은 뒤 **반드시** 도장을 다시 찍고 올리세요.

```bash
python tools/stamp_version.py
```

## 4. 관리하기

- **글 감추기** — Table Editor → `plans` → 그 줄의 `hidden` 을 `true` 로.
  지우는 것보다 낫습니다. 지우면 그 사람이 같은 코드로 다시 올릴 수 있습니다.
- **완전히 지우기** — 같은 화면에서 행 삭제.
- **게시판 끄기** — `board.js` 의 `URL`·`KEY` 를 빈 문자열로 되돌리면 화면에서 사라집니다.

## 5. 알아 둘 것

**도배를 완전히 막지는 못합니다.** 브라우저 쪽 1분 쿨다운이 있지만 마음먹으면 우회됩니다.
진짜 방어선은 위의 표 제약(코드 모양·유일 제약·길이)입니다. 그걸로도 모자라면
Supabase 의 **Edge Function** 을 앞에 두고 IP 단위로 제한해야 하는데, 지금은 과합니다.
오픈베타에서 실제로 도배가 생기면 그때 붙이세요.

**무료 티어 한도** — 프로젝트가 **7일 동안 아무 요청도 없으면 잠깁니다.**
대시보드에서 한 번 깨우면 됩니다. 저장 공간은 이 용도로는 남아돕니다
(한 줄이 200바이트 남짓이라 수십만 줄을 넣어도 여유).

**개인정보를 받지 않습니다.** 닉네임·한 줄 소개·구단·대전 코드뿐입니다.
이메일이나 로그인은 없습니다.
