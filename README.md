# KMD26 · 개리그 매니저 듀얼

사용자끼리 **전술로 대전**하는 축구 감독 게임입니다.
서버가 없습니다. 라인업을 코드로 만들어 링크로 주고받으면, 양쪽 브라우저에서 **완전히 동일한 경기**가 재생됩니다.

```
[A] 라인업 작성 → 초대 링크 게시판에 올림
[B] 링크 클릭 → 자기 라인업 작성 → 경기 관람 → 결과 링크를 A에게
[A] 결과 링크 열기 → 토씨 하나 안 틀리고 같은 경기
```

> 🚧 **개발 중입니다.** 현재 **단계 1(엔진 추출)** 까지 완료됐습니다.

---

## 지금 확인할 수 있는 것 — 단계 1

매치엔진이 화면 없이 90분을 완주하는지 확인하는 페이지가 있습니다.

**ES 모듈을 쓰므로 파일을 그냥 열면 안 되고, 로컬 서버가 필요합니다.**

```bash
python -m http.server 8000
```

그다음 브라우저에서 <http://127.0.0.1:8000/test/headless.html> 를 열고 **경기 1판 돌리기**를 누르세요.

검토 기준 6가지가 자동으로 표시됩니다.

| 확인 항목 | 통과 조건 |
|---|---|
| 엔진이 예외 없이 완주 | `done === true` |
| 경기 시계 90분 도달 | 5,400초 |
| DOM 참조 없이 실행 | 모듈 로드 성공 |
| 이벤트 기록 | 1건 이상 |
| 슈팅 발생 | 1회 이상 |
| 심판 배정 | 이름 표시 |

`10판 연속` 버튼으로 판당 계산 시간과 평균 득점도 볼 수 있습니다.

> ⚠️ 이 단계의 스쿼드는 **합성 데이터**입니다. 실제 선수 능력치는 단계 4에서 붙입니다.
> ⚠️ 아직 **결정론이 없습니다.** 같은 대진이라도 매번 결과가 다릅니다. 단계 2에서 시드를 붙입니다.

## 구조

```
src/engine/
  kernel.js    KM26 매치엔진 추출본 (자동 생성 · 직접 수정 금지)
  stubs.js     엔진이 참조하는 전역 문맥 스텁 (G · famK · refBias 등 5개)
  duel.js      듀얼 경기 구동부 (createMatch 대체 + 헤드리스 실행)
tools/
  extract_engine.py   추출기 — 원본이 갱신되면 다시 돌리면 됩니다
test/
  fixture.js   합성 스쿼드
  headless.html 단계 1 확인 페이지
```

### 커널을 다시 뽑으려면

원본 KM26이 업데이트되면 커널만 다시 뽑습니다. 손으로 고칠 필요가 없습니다.

```bash
python tools/extract_engine.py <KM26 index.html 경로> src/engine/kernel.js
```

추출기는 `MatchSim`에서 시작하는 **의존성 폐포**를 계산해 필요한 선언만 원본 순서대로 뽑습니다.
전역 상태·UI는 경계에서 끊고 `stubs.js`가 대신합니다.

## 설계 원칙

| 원칙 | 이유 |
|---|---|
| **커널은 절대 손대지 않는다** | 원본이 갱신되면 다시 뽑아야 하므로. 수정이 필요하면 스텁이나 래퍼에서 |
| **시즌 누적값은 전부 고정** | 조직력 100 · 사기 75 · 컨디션 100. "누가 시즌을 오래 굴렸는가"가 승부에 끼어들면 안 됨 |
| **포지션 능숙도는 유지** | 이게 없으면 라인업을 짤 이유가 사라짐 |
| **시드는 양쪽 코드에서 유도** | 어느 쪽도 유리한 결과를 골라 공유할 수 없게 |

전체 설계는 `개리그매니저듀얼_설계서_v2.md` 를 보세요.
